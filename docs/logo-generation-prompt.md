# WakeHook logo prompt

Paste this prompt into ChatGPT image generation to explore a logo for WakeHook.

> Create a polished, original logo for **WakeHook**, an open-source Android alarm clock that people can also ask their AI agent to set. The product wakes people reliably while keeping control with the user: alarms ring locally on the phone, and agent requests sync through the user's own cloud storage. The brand should feel calm, dependable, thoughtful, and quietly technical—not like a surveillance product or a generic AI startup.
>
> Design one distinctive, simple symbol that combines the idea of waking up with a subtle “hook” or connection: for example, a sunrise arc meeting a clean clock hand, or a small bell/clock cue formed from one continuous stroke. Keep the connection metaphor secondary and avoid literal chain links, robot heads, brains, magic wands, or Google-specific imagery. The symbol must remain recognizable at Android launcher-icon size and work in one color.
>
> Pair the symbol with a clean, humanist sans-serif wordmark reading **WakeHook** exactly, with correct capitalization and spelling. Create a primary horizontal lockup on a plain near-black background, using warm sunrise amber as a restrained accent with soft ivory text. Also show the symbol alone as a square app icon on a deep charcoal background. Use a small, controlled palette; crisp vector-like geometry; balanced negative space; and strong contrast. The icon should have no tiny details, gradients that reduce legibility, drop shadows, mockup devices, or decorative background art.
>
> Present a professional identity exploration on a clean flat canvas: one primary horizontal logo and one separate square app icon, both front-facing and sharply rendered. Keep all lettering minimal and legible. Do not add slogans or extra copy. This should look suitable for an open-source utility people trust with waking up on time.

## Useful follow-up variations

- Ask for a monochrome version suitable for the Android notification small icon.
- Ask for an app-icon-only version with the symbol optically centered and safe within a rounded-square mask.
- Ask for a light-background lockup while preserving the same symbol and proportions.
- If image generation distorts the wordmark, generate the symbol without text and set “WakeHook” separately in the app's chosen typeface.
