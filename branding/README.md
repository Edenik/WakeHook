# WakeHook mark

A clock arc and a hook-shaped hand: a direct reference to the alarm and the agent connection. The detached twelve-o'clock dot suggests the first light above the dial.

- Sunrise amber `#FFB74D` on night `#0E0F14`.
- `wakehook-mark.svg` is a standalone vector preview with a rounded background.
- Android uses `ic_launcher_foreground.xml` for both adaptive launcher shapes and themed monochrome icons.
- `ic_wakehook.xml` is the tightly framed in-app mark; `ic_alarm.xml` is the white notification variant.
- Launcher artwork remains inside the adaptive icon safe region. Android supplies the final launcher mask and themed color.

Keep the mark unmirrored in RTL layouts, with no added text inside the icon.
